# Інтеграція Kyivvodokanal Cabinet

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/integration)

Кастомна інтеграція для Home Assistant для моніторингу даних кабінету клієнта Kyivvodokanal Kyiv (Україна): платежі, показання лічильників води, тарифи та інформація про підписку.

## Можливості

- **Моніторинг платежів**: Дата останньої оплати
- **Показання лічильників**: Останні показання лічильників гарячої та холодної води, дати повірки
- **Тарифи**: Поточні тарифи на холодну воду, водовідведення та абонплату
- **Інформація про рахунки**: Поточний борг та сума до сплати
- **Передача показань**: Служба для передачі показань лічильників через Home Assistant
- **Журнал активності**: Ключові події відображаються в Logbook Home Assistant
- **Перезавантаження без рестарту**: Інтеграція підтримує перезавантаження через UI
- **Українська локалізація**: Повна підтримка української мови

## Встановлення

### Варіант 1: HACS (Рекомендовано)

1. Переконайтеся, що [HACS](https://hacs.xyz/) встановлений у вашому екземплярі Home Assistant
2. Додайте це репозиторій як кастомний репозиторій у HACS:
   - Перейдіть до HACS → Інтеграції
   - Натисніть три крапки (⋮) у верхньому правому куті
   - Виберіть "Кастомні репозиторії"
   - Додайте `https://github.com/avoloshyn79/ha-kyivvodokanal-cabinet` як URL репозиторію
   - Виберіть "Інтеграція" як категорію
3. Знайдіть "Kyivvodokanal Cabinet" у HACS та встановіть його
4. Перезапустіть Home Assistant

### Варіант 2: Ручне встановлення

1. Завантажте папку `kyivvodokanal_cabinet` з цього репозиторію
2. Скопіюйте її до директорії `custom_components` вашого Home Assistant:
   ```
   <config_directory>/custom_components/kyivvodokanal_cabinet/
   ```
3. Перезапустіть Home Assistant

## Конфігурація

1. Перейдіть до **Налаштування** → **Пристрої та сервіси** → **Додати інтеграцію**
2. Знайдіть "Kyivvodokanal Cabinet" та виберіть його
3. Введіть наступну інформацію:
   - **Назва**: Дружня назва для вашого екземпляра інтеграції
   - **Базовий URL API**: `https://my.vodokanal.kiev.ua` (за замовчуванням)
   - **Сесійний cookie**: Ваш cookie аутентифікації з сайту Kyivvodokanal
   - **Заголовок Authorization**: Bearer token (необов'язково)
   - **Інтервал оновлення**: Як часто оновлювати дані (у хвилинах, за замовчуванням: 360)

### Як отримати сесійний cookie

1. Відкрийте браузер та перейдіть на [https://my.vodokanal.kiev.ua](https://my.vodokanal.kiev.ua)
2. Увійдіть до свого облікового запису
3. Відкрийте інструменти розробника браузера (F12)
4. Перейдіть до вкладки **Network**
5. Оновіть сторінку або перейдіть до будь-якої сторінки з даними
6. Знайдіть будь-який запит до API (наприклад, `/api/warehouse/consumer/payments/history`)
7. Скопіюйте повне значення заголовку `Cookie` з цього запиту
8. Вставте це значення до конфігурації інтеграції

**Примітка**: Cookie може закінчитися або стати недійсним — в такому разі потрібно оновити його в налаштуваннях інтеграції.

## Служби (Services)

### `kyivvodokanal_cabinet.update_data`
Примусове оновлення даних з API без очікування інтервалу.

### `kyivvodokanal_cabinet.submit_readings`
Передача показань лічильника до Kyivvodokanal.

| Параметр | Обов'язковий | Опис |
|----------|:---:|------|
| `counter_id` | Так | ID лічильника |
| `reading_value` | Так | Значення показання |
| `factor_type_code` | Ні | Код типу фактора |

## Приклад автоматизації передачі показань

Автоматична передача показань лічильників 26-го числа кожного місяця о 09:00.

> **Перед використанням**: замініть `123456` та `654321` на реальні ID ваших лічильників.  
> ID лічильника можна знайти в логах Home Assistant після першого оновлення даних  
> (увімкніть debug-логування та пошукайте `counter_id`).

```yaml
automation:
  - alias: "Передача показань води"
    trigger:
      - platform: time
        at: "09:00:00"
    condition:
      - condition: template
        value_template: "{{ now().day == 26 }}"
    action:
      - service: kyivvodokanal_cabinet.submit_readings
        data:
          counter_id: 123456
          reading_value: "{{ states('sensor.ostannie_pokazannia_hariachoyi_vody') | float }}"
      - service: kyivvodokanal_cabinet.submit_readings
        data:
          counter_id: 654321
          reading_value: "{{ states('sensor.ostannie_pokazannia_kholodnoyi_vody') | float }}"
```

Якщо потрібно передавати показання вручну — достатньо викликати службу через  
**Інструменти розробника** → **Служби** → `kyivvodokanal_cabinet.submit_readings`.

## Журнал активності (Logbook)

Інтеграція записує в Logbook Home Assistant наступні події:

| Подія | Коли з'являється |
|-------|-----------------|
| `Дані оновлено. борг: X грн, до сплати: Y грн` | Після кожного успішного оновлення даних |
| `Передано показання лічильника 123456: 42.5 м³` | Після успішної передачі показань |
| `Помилка передачі показань лічильника 123456: ...` | При помилці передачі показань |

> **Примітка**: Числові сенсори (`SensorStateClass.MEASUREMENT`) — борг, тарифи, показання лічильників —
> не з'являються в Logbook. Це стандартна поведінка Home Assistant: числові ряди зберігаються
> в статистиці та доступні через вкладку **Історія** на картці кожного сенсора.

## Перезавантаження інтеграції

Інтеграція підтримує перезавантаження без повного рестарту Home Assistant:
**Налаштування** → **Пристрої та сервіси** → **Kyivvodokanal Cabinet** → три крапки (⋮) → **Перезавантажити**

## Вирішення проблем

### Помилка аутентифікації
- Переконайтеся, що сесійний cookie дійсний та не закінчився
- Вийдіть та знову увійдіть на сайт Kyivvodokanal для отримання свіжого cookie
- Переконайтеся, що ви скопіювали **повне** значення заголовку `Cookie`, а не лише його частину

### Дані недоступні
- Переконайтеся, що обліковий запис має історію платежів та показання лічильників
- Перевірте логи Home Assistant на повідомлення від `kyivvodokanal_cabinet`

### Невірні тарифи або показання
- Перевірте, чи API повертає актуальні дані в кабінеті на сайті
- Збільшіть рівень логування для детальної діагностики:
  ```yaml
  logger:
    logs:
      custom_components.kyivvodokanal_cabinet: debug
  ```
